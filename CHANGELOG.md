# Changelog

## 0.1.0-dev

Initial functional foundation:

- dependency-free PHP 8.2+ core;
- SQLite and MySQL/MariaDB persistence;
- pages, articles and events;
- draft/publish scheduling;
- navigation;
- media metadata and controlled uploads;
- SEO metadata;
- admin/editor login and admin UI;
- read-only public JSON API;
- host-application integration facade;
- CLI setup, tests and CI.
